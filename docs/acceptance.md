# Проверка и выпуск

| Входные оценки | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| 0, 0, 0, 0 | Список пуст | Список пуст |
| 4, 2, 1, 1 | Первое место — программная инженерия, 100% | Совпало |
| 0, 0, 0, 4 | Первое место — дизайн цифровых продуктов | Совпало |
| 2, 2, 2, 2 | Все направления отсортированы по баллу | Совпало |

Четыре сценария проверены запуском функции ранжирования в Node.js. Для проверки интерфейса нужно открыть index.html, заполнить анкету и сверить её вывод с этой таблицей.

Для выпуска собирается согласованная ветка main. Отметка v0.1.0 указывает на первый учебный выпуск.
