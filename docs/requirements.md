# Постановка задачи

Абитуриент сравнивает направления по тому, чем ему интересно заниматься. При первом просмотре названия программ часто мало что говорят о будущих задачах. Прототип помогает выбрать направления для дальнейшего изучения.

Анкета спрашивает об интересе к программированию, анализу данных, организации процессов и дизайну. Оценка каждого интереса лежит в диапазоне от 0 до 4. Пользователь может указать несколько выраженных интересов. Прототип выводит все направления в порядке убывания балла и показывает вклад каждого ответа в первое место.

Для направления с профилем p и ответов a коэффициент совпадения равен скалярному произведению a и p, делённому на произведение их евклидовых норм. Результат выводится в процентах. При равенстве оценок сохраняется порядок направлений в каталоге. Если все ответы нулевые, система просит указать хотя бы один интерес. Округление применяется только при выводе.

Анкета работает в браузере, без регистрации. Ответы не записываются на диск и не отправляются по сети. Учебные данные описывают примеры, поэтому по результату следует изучить официальные программы и правила приёма выбранного вуза.

## Критерии приёмки

1. Все четыре вопроса можно заполнить с клавиатуры.
2. Нулевые оценки не формируют список рекомендаций.
3. Ответы, совпадающие с эталонным профилем, дают ему 100 процентов.
4. Список сортируется по баллу и показывает объяснение первого результата.
5. Для работы не требуется подключение к сети.
