# Выбор направления обучения

Учебный прототип системы поддержки решений для абитуриента. Анкета сопоставляет интересы пользователя с четырьмя примерами направлений и показывает, какие ответы повлияли на результат.

Откройте `index.html` в браузере. Укажите интерес к каждой области по шкале от 0 до 4 и нажмите «Сравнить направления». Примеры предназначены для демонстрации расчёта и не описывают правила приёма конкретного вуза.
